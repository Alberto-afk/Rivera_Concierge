# Recursos atmosféricos

Ilustraciones decorativas originales generadas con ImageGen para Rivera Concierge: montaña nocturna, nube con transparencia y planeta con transparencia. No representan trabajos del taller. Inspiración de movimiento: Montfort Group; no se descargaron sus imágenes.

Los PNG originales se convirtieron a WebP conservando transparencia. Montaña: 1600 y 800 px; nube: 1200 px; planeta: 800 y 320 px. Sin dependencias de procesamiento de imágenes en producción.
